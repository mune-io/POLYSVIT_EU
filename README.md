# POLYSVIT — landing page

Лендинг компании POLYSVIT (Szczecin) — поставщика насосов, теплообменников,
сепараторов и деаэраторов для пищевой, фармацевтической и
нефтеперерабатывающей/нефтехимической промышленности. Официальный партнёр
Alfa Laval, SPX FLOW/APV и Seital.

Сделано на React + Vite, без сторонних UI-библиотек. Три языка интерфейса —
PL / EN / RU (переключатель в шапке), переводы лежат в
[src/i18n/translations.js](src/i18n/translations.js).

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

- `src/components/` — секции лендинга (Header, Hero, Overview, Products,
  Industries, Partners, Contact, Footer) и иконки.
- `src/i18n/` — переводы и контекст языка.
- `src/company.js` — реквизиты компании (адрес, телефон, KRS/NIP/REGON).

## Что нужно донастроить

- Контактная форма в разделе «Kontakt» пока работает только на клиенте
  (показывает подтверждение, но никуда не отправляет данные) — реального
  email для приёма заявок предоставлено не было. Чтобы форма реально
  отправляла письма, подключите бэкенд/сервис (например, Formspree,
  собственный API) в `src/components/Contact.jsx`.
- Логотип и фирменные цвета не предоставлялись — используется
  сгенерированная промышленная палитра (тёмно-синий/графит + акцентный
  синий). При наличии логотипа замените `.brand-mark` в
  [src/App.css](src/App.css) и обновите `public/favicon.svg`.
